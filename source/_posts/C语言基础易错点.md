# 一、自增

**不能对常量**自增！自增**只能**针对**变量**或**数组元素**

### 1.**float变量可以自增吗？**

**可以！**

```
float a = 1.25;
a++;  // 这是合法的！
```

- `a++` 等价于 `a = a + 1.0f`
- 自增后，`a` 的值变为 `2.25`



### 2.**宏定义可以自增吗？**

**绝对不可以！**

```
#define b 2
b++;  // 编译错误！
```

- 宏是**预处理器指令**，不是变量
- 在编译前，预处理器会把所有 `b` 替换为 `2`
- 所以 `b++` 实际上变成了 `2++`
- **只有存储在内存中的变量才能被修改**。宏只是文本替换，不存在于运行时内存中



### 3.指针的自增

```
int  a[5] = {0,1,2}; 
int *p = a;
p++;
```

- p++ 或 p = p + 1 中的 "1" 是一个指针**所指向类型的长度单位**，不是字节数
- 当执行 p++ 或 p = p + 1 时，编译器会**自动将 1 乘以 sizeof(int)** 来调整地址（地址增加4）
- **p = p + sizeof(int) 是错误的！**

# 三、类型转换：强制转换与自动提升

### 1. 强制类型转换（cast）

```
double a;
(int)a;
```

- 由程序员**显式指定**
- 告诉编译器：**“我知道我在做什么”**
- 转换只作用于**该子表达式本身**
- 不会“冻结”后续的类型提升



### 2. 自动类型提升（隐式转换）

在C语言中，当**不同类型**的数据一起运算时，编译器会自动进行**类型转换**。

这套机制可以分为三大场景：

#### 规则 1：整数提升（Integer Promotion）

任何**小于 `int` 的类型**参与运算时，**先提升为 `int`**：

```
char a = 'A';      // 65
short b = 100;
int result = a + b;  // a和b先提升为int，再相加

// 实际过程：char(65) → int(65), short(100) → int(100)
```

- `char / short` → 提升为 `int`（或 `unsigned int`）
- `int` 及以上类型不受影响



#### 规则 2：类型降级（Demotion）

这是**从宽到窄**、**可能丢失数据**的转换，通常发生在赋值时：

```
int big_num = 300;     // 4字节：00000000 00000000 00000001 00101100
char small = big_num;  // 只取最低8位：00101100 = 44

// 注意：300 > 127，可能溢出！
```

- `int` → 降级为 `char`本质是**二进制截断**：只保留最低8位
- 负数直接保留低8位（以补码形式）
- 可能发生溢出或符号变化



#### 规则 3：**通常算术转换（Usual Arithmetic Conversions）**

当两个不同类型的数据一起运算时，按照以下**优先级链**转换：

```
long double (最高优先级)
↑
double
↑  
float
↑
unsigned long long
↑
long long
↑  
unsigned long
↑
long
↑
unsigned int
↑
int (最低优先级)

// 浮点型 > long型 > int型
```



##### 1. 浮点数优先

只要表达式中**出现浮点类型**，整数无条件转换为浮点数：

```
int + double   // int → double
```

- **另一边**的整数 **会被转换为浮点**
- 表达式结果是**精度更高的浮点类型**



##### 2. 整数之间：

如果没有浮点数，则向**更宽（能表示更大范围）的类型**转换：

```
long + int   // int → long
```



**3.有符号 vs 无符号的特殊规则：**

这是**最容易出错**的地方：

```
int a = -1;          
// 有符号：-1，在内存中的二进制形式为：1111 1111 1111 1111 1111 1111 1111 1110（4294967295）
unsigned int b = 10; 
// 无符号：10，在内存中的二进制形式为：0000 0000 0000 0000 0000 0000 0000 1010（10）

if (a < b) {         // 危险！-1被转换为很大的无符号数
    // 实际比较：4294967295 < 10 → false
    // 但是期望这里是true
}
```

**核心规则**：向**能表示更大范围的类型**转换

- 如果有符号类型能**完整表示**无符号类型的范围，则无符号转有符号
- 否则，有符号转无符号（可能产生意外结果）

# 四、指针这一块

### 1.对指针的理解

```
int n = 0; 

int *p =&n; 
```

int*：**存int变量地址的**变量类型（个人理解，可能不严谨）

p：**存放int变量地址**的变量名



### 2.给指针赋值

```
int *p = &n;
int **q = &p;
```

```
p = q; // 错误赋值
```

**错误！**

p的类型是 int *，q的类型是 int**，

**int * 和 int******** 是**完全不同**的指针类型（指针的“层级”不匹配），C 不会自动把 int ** 转成 int *



```
p = 1; // 错误赋值
```

**错误！**

p的类型是 int *，1的类型是 int



```
*p = 5; //正确赋值
```

**正确！**

*p即对p进行解引用，实际上是在对n操作

# 五、字符串

### 字符串终止符 '\0'

\0 的**ASCII码值为 0**，内存表示为00000000

所有C语言字符串**都以\0结尾**，作为字符串终止符

```
char str[] = "Hello";  // 实际存储：'H' 'e' 'l' 'l' 'o' '\0'
```

```
char null = '\0';
printf("%d\n", null);  // 输出'\0'的ASCII码，输出: 0
```

### **数值0**

0的**ASCII码为0**，内存表示为00000000

```
char zero = 0;  // 把一个int类型的值赋给char类型变量，发生自动类型转换
                // 只保留int 0（32位0的低8位），隐式转换后与'\0'（8位0）相同
printf("%d\n", zero);  // 输出0的ASCII码，输出: 0
```

### **数字字符'0'**

'0'的**ASCII码为48**，内存表示为00110000

```
char zero = '0';
printf("%d\n", zero);  // 输出: 48
```

### 常见误区

```
char str[] = "0";
// 实际存储: '0'和 '\0'
// 长度: 2个字符: '0' + '\0'
```

```
char str[] = "";
// 实际存储: 只有'\0'
// 长度: 1个字符: '\0'
```

14.**赋值**：=，+=，-=，*=，/=

15.**逗号运算**：(xx,xx,xx,xx)

# 七、单目运算符：逻辑非!

`!`（逻辑非）运算符可以作用于**任何标量类型**（整数、浮点数、指针），它会进行**布尔化转换**。

**布尔化转换规则**：`!x` 等价于 `(x == 0 ? 1 : 0)`

**零值转换为1，非零值转换为0**

# 八、数学运算函数

### **1. 绝对值函数**

```
abs(int x);             // 整型绝对值
labs(long x);           // 长整型绝对值
fabs(double x);         // 浮点型绝对值
```



### **2. 幂运算**

```
pow(double x, double y);  // x的y次方：pow(2, 3) = 8.0
sqrt(double x);           // 平方根：sqrt(9) = 3.0
cbrt(double x);           // 立方根(C99)：cbrt(27) = 3.0
```



### **3. 指数与对数**

```
exp(double x);           // e的x次幂：exp(1) ≈ 2.718
log(double x);           // ln：log(2.718) ≈ 1.0
log10(double x);         // lg：log10(100) = 2.0
log2(double x);          // 以2为底对数：log2(8) = 3.0
```



### **4. 三角函数**

```
sin(double x);           // 正弦：sin(M_PI/2) = 1.0
cos(double x);           // 余弦：cos(0) = 1.0
tan(double x);           // 正切：tan(0) = 0.0

asin(double x);          // 反正弦：asin(1) = π/2
acos(double x);          // 反余弦：acos(0) = π/2
atan(double x);          // 反正切：atan(1) = π/4
```

x应该为弧度 π/3，而非度数 60
